# ADR-002: 같은 PostgreSQL 위 확장, v0.1은 관계형 모델

상태: v0.1 구조 확정 요구 기록. v1.0 구현 선택은 보류.

v0.1은 Ontology YAML의 클래스·동사형 관계를 일반 FK·연결 테이블로 표현한다. 모든 엔티티 UUID와 subject type namespace를 유지한다. 병리 Task·서비스는 그래프 DB에 의존하지 않는다.

v1.0에서 실제 관계 탐색 요구와 부하를 측정한 후 PostgreSQL 재귀 CTE 또는 그래프 확장을 비교한다. Apache AGE·Neo4j·별도 그래프 저장소는 지금 설치하지 않는다. YAML에 관계가 있다는 이유만으로 Knowledge Graph 구현 완료라고 부르지 않는다.

장점은 원내 단일 DB 백업·권한·파기를 유지하는 것이다. 다중 모듈이 생기면 관계 소유자·보유정책을 함께 등록해야 한다. C1·C2·C3·C5를 테스트해 향후 변화가 기존 모듈의 식별자와 서비스를 깨지 않게 한다.
