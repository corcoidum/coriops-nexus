# 내부 관리계획 부속 초안

**법률 자문이 아닌 초안, 원장 결재·확인 필요.** 기관명·책임자·결재일·시행일은 미기입 상태다. 이 문서는 내부 관리계획 전체를 대체하지 않는다.

| 항목 | 운영 통제 초안 | 원장 확인 |
|---|---|---|
| 역할 | 책임자·대체 점검자·계정관리자 지정, 개인 계정만 | Q01 |
| 취급 범위 | 차트번호·이름·생년월일·성별, 시행·검체·상태·기한만 | 보유근거 Q06 |
| 권한 | 입사·업무 변경·퇴사 즉시 최소권한 조정, 이력 최소 3년 | 변경 담당·자기 승인 경계 |
| 인증 | 10자 이상·argon2id, 5회/30분 잠금, 15분 미사용 종료 | 교육·분실 계정 복구 |
| 접근통제 | 원내 업무 PC allowlist, 원격·모바일 지원 없음, Windows 방화벽 | Q10·PC 목록 |
| 로그 | 서비스 AccessLog·매월 점검, 체크포인트 독립 보관 | 점검 주기·보유 Q06 |
| 출력·복사 | 기본 마스킹·보호된 인쇄화면, 인쇄물 회수·파쇄, 파일 Export 없음 | 장소·회수 담당 |
| 파기 | 후보→책임자 승인→의존성 재검증→hard delete→매체 확인 | Q06 |
| 백업 | 일일 공개키 암호화·로컬 매체·최대 30일 제안, 정기 복원 | Q06/Q09 |
| 장비 | 잠금 장소, BitLocker 등 디스크 암호화·키 보관 검토, OS/백신 업데이트 | 현장 확인 |
| 교육 | 임상 소견·연락처를 메모에 넣지 않기, 화면·인쇄 유출 방지 | 주기·참석 기록 |
| 사고 | 격리·증거 보존·신고 판단·복구·파기 재적용 | 책임자·연락체계 |

패키지·이미지·백신·OS 업데이트 설치 단계와 앱 runtime의 외부 통신 금지는 구분한다. 업데이트는 승인된 작업 시간에 수행하고 runtime egress를 다시 검증한다. 서버·Docker Desktop 자동 시작과 절전 해제를 검증한다.
