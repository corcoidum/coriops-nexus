# 검진 혈액검체 결과 대장 — 계획 초안

작성일: 2026-10-25. 상태: **계획 초안. 양식(열)과 업무 기준을 사용자가 확인하기 전에는 코드를 작성하지 않는다.**

씨젠에 위탁한 검진 혈액검체 결과를 확인해 정리하는 대장을 조직검체 대장과 **별도로** 만든다. 조직검체 대장(`endoscopy_pathology`)은 지금 방식대로 계속 진행하며, 두 작업이 서로의 코드·설정·시험을 바꾸지 않게 나눈다.

[roadmap](roadmap.md)의 v0.2 "Lab 파일 import"·v0.3 "검진 F/U"를 앞당기는 요청이다. 이번 계획은 조직검체 대장과 같은 **합성 자료 전용 프로토타입** 수준에서 시작하며, 정식 Phase Gate·실데이터 전환·씨젠 자동 조회(ADR-005 보류)를 승인한 것이 아니다.

## 조직검체 대장과 다른 점

| 항목 | 조직검체 대장 | 혈액검체 대장 (예상, 확인 필요) |
|---|---|---|
| 결과 형태 | 서술형 소견 → 병원 약어로 수기 기입 | 항목별 수치 + 단위 + 참고치 + 씨젠 H/L 표시 |
| 한 행 단위 | 접수 1건 | 수진자×검사일 1행(가로형) 또는 수진자×항목 1행(세로형) — B02 |
| 약어 사전 | 필요(Q19 대기) | 대부분 불필요할 가능성. 항목 코드·이름 대응표가 대신 필요 |
| 주요 위험 | 결과 누락, 원장 F/U 지시 누락 | 이상치·critical value 보고 누락, 재검 안내 누락, 항목 누락 |
| 후속 판단 | 다음 내시경 시점 = 원장 | 재검·추가검사·상담 필요 여부 = 원장 (시스템이 판단하지 않음) |

시스템은 씨젠이 표시한 H/L·참고치를 그대로 옮길 뿐, 자체 기준으로 정상/이상을 새로 분류하지 않는다. 병원 내부 기준으로 강조 표시할지는 원장이 정한 기준이 있을 때만 설정값으로 추가한다(B05).

## 병행 작업 규칙

- 코드: `app/modules/screening_lab/`에 새 모듈로 만든다. `endoscopy_pathology`를 import하지 않는다. 공통으로 쓸 코드가 생기면 복사하지 않고 그때 kernel 이동을 따로 제안한다(ADR-004 C1).
- 설정: `config/lab_ledger_mapping.yaml`을 새로 만든다. 기존 `config/ledger_mapping.yaml`은 건드리지 않는다.
- 시험: `tests/prototype/test_lab_*.py`로 분리한다. 기존 75개 시험이 그대로 통과해야 한다.
- 화면: 수동 대시보드에 붙일 경우 별도 경로(`/dashboard/lab`)로 추가하고 기존 `/dashboard` 동작은 바꾸지 않는다.
- 자료: 이름이 `테스트`로 시작하는 합성 자료만 사용한다. 실제 결과지·환자 파일·씨젠 계정은 받지 않는다.

## 단계

| 단계 | 할 일 | 완료 기준 | 선행 조건 |
|---|---|---|---|
| L0 | 현재 수기 대장 양식·업무 흐름 확인 | B01~B06 답변, 열 목록 확정 | 사용자 답변 |
| L1 | `lab_ledger_mapping.yaml` + 합성 fixture 10~20건 | 열 순서가 사용자 양식과 동일, 시험으로 고정 | L0 |
| L2 | 합성 Excel 대장 생성 | 숫자·단위·H/L 보존, 중복 키 재실행 시 행 증가 0, 직원 입력 열 보존 | L1 |
| L3 | 수동 대시보드 혈액 탭 | 미확인·이상 표시 건·원장 보고 대기 목록, 원장 지시 수기 기록 | L2 + B04 |
| L4 | 씨젠 다운로드 파일 import | 파일 형식 확인 후 parse→validate→preview→commit (C7) | B06 + ADR-005 재검토 |

각 단계가 끝나면 보고하고 확인을 받은 뒤 다음 단계로 간다. L4는 조직검체 쪽 ADR-005 결정과 함께 정한다.

## 확인 질문 — L0

| ID | 질문 | 왜 필요한가 |
|---|---|---|
| B01 | 지금 쓰는 혈액 결과 대장(Excel/수기)의 열 이름을 순서대로 알려줄 수 있는가? 환자값 없이 헤더만 | L1 매핑의 원천. 조직검체 17열과 같은 방식 |
| B02 | 한 행이 "수진자 1명·검사일 1회"인가, "검사 항목 1개"인가? | 가로형/세로형에 따라 중복 키·Excel 구조가 달라짐 |
| B03 | 대장에 넣는 검사 범위는? (국가 일반검진, 암검진 혈액, 종합검진 추가항목, 일반 외래 채혈 포함 여부) | 대상 항목 목록과 행 수 결정 |
| B04 | 결과 확인 후 원장 보고 대상은 어떤 경우인가? (씨젠 H/L 전부, critical value만, 특정 항목만) | 대시보드 "보고 대기" 목록 기준. 시스템이 임의로 정하지 않음 |
| B05 | 씨젠 표시 외에 병원 자체 강조 기준(예: 특정 항목 수치)이 있는가? 있다면 원장 승인 기준인가? | 있을 때만 설정값으로 추가 |
| B06 | 씨젠 결과조회 화면에서 혈액 결과를 파일(Excel/CSV/PDF)로 내려받을 수 있는가? 헤더 모양만 | L4 가능 여부. 계정·실제 파일은 받지 않음 |

## 하지 않는 것

- 수치로 질환·재검 필요 여부·검진 판정을 자동 결정하지 않는다.
- 씨젠 자동 로그인, 의사랑 DB 연동, 공단 검진 결과 전송을 이번 계획에 넣지 않는다.
- 결과 원문 PDF를 저장하지 않는다. 저장 범위는 열 확정 후 개인정보 대응표와 함께 정한다.
