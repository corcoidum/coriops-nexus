# 검진 혈액검체 결과 대장 — 계획 초안

작성일: 2026-10-25. 상태: **L0 답변 반영, L1·L2 합성 프로토타입 구현.** 실제 결과 파일·씨젠 접속·실데이터 전환은 미착수.

씨젠에 위탁한 검진 혈액검체 결과를 확인해 정리하는 대장을 조직검체 대장과 **별도로** 만든다. 조직검체 대장(`endoscopy_pathology`)은 지금 방식대로 계속 진행하며, 두 작업이 서로의 코드·설정·시험을 바꾸지 않게 나눈다.

[roadmap](roadmap.md)의 v0.2 "Lab 파일 import"·v0.3 "검진 F/U"를 앞당기는 요청이다. 이번 계획은 조직검체 대장과 같은 **합성 자료 전용 프로토타입** 수준에서 시작하며, 정식 Phase Gate·실데이터 전환·씨젠 자동 조회(ADR-005 보류)를 승인한 것이 아니다.

## 조직검체 대장과 다른 점

| 항목 | 조직검체 대장 | 혈액검체 대장 (예상, 확인 필요) |
|---|---|---|
| 결과 형태 | 서술형 소견 → 병원 약어로 수기 기입 | 항목별 수치 + 단위 + 참고치 + 씨젠 H/L 표시 |
| 한 행 단위 | 접수 1건 | 수진자 1명의 전체 결과 1행 (L02) |
| 약어 사전 | 필요(Q19 대기) | 불필요. 결과란에 이상 항목만 `항목 값 H/L`로 적음 (L04) |
| 주요 위험 | 결과 누락, 원장 F/U 지시 누락 | 이상치·critical value 보고 누락, 재검 안내 누락, 항목 누락 |
| 후속 판단 | 다음 내시경 시점 = 원장 | 재검·추가검사·상담 필요 여부 = 원장 (시스템이 판단하지 않음) |

시스템은 씨젠이 표시한 H/L·위급치를 그대로 옮길 뿐, 참고치와 비교해 정상/이상·위급치를 새로 판정하지 않는다.

- L11 (B13, 2026-10-26): 추가 B형·C형간염 검사도 분류(일반/간) 칸에 `추가b형간염`·`추가c형간염`으로 적는다. 여러 개면 쉼표로 잇는다(L07).

- L16 (B17): 분변잠혈은 별도 탭·별도 대장(`분변잠혈검사 결과기록대장`)으로 운영한다. 구현 전 B20 확인.

- L19 (B19, 2026-10-26 정정): 씨젠에서 내려받은 PDF는 **글자를 선택할 수 있다.** 이후 원내 PC에서 PDF 글자를 읽어 미리보기 → 직원 확인 → 저장하는 방식으로 개선할 수 있다(외부 전송·OCR 없음, 새 패키지 필요).

## 씨젠 결과지(PDF) 형식 — B11, 2026-10-26

사용자가 이름·번호 없는 결과지 표 부분 4장을 보여주었다. 저장소에는 **표 구조·보험코드·검사명만** 기록하고 결과 수치는 옮기지 않는다(AGENTS.md 절대 규칙 1).

- 환자 1명당 PDF 1부. 표는 **검사 항목 1개 = 1행**(세로형)이다. 장부는 수진자 1명 = 1행이므로 여러 행을 한 줄 `결과`로 모은다.
- 열 5개: `보험코드 · 검사항목 · 검사결과 · 판정 · 참고치`
- 검사항목은 `[검진] ` 접두어가 붙는다(예: `[검진] AST (GOT)`).
- 판정 열에는 `H`(빨강)·`L`(파랑)만 보였다. 정상이면 빈칸. **보여준 4장에는 위급치 표시가 없었다**(B15).
- 정성 검사(간염·분변잠혈)는 결과가 `Negative 0.30`, `Positive …`처럼 글자+수치이고 **판정 열이 비어 있다.** 지금 규칙(H/L만 기록)대로면 Positive도 결과에 남지 않는다(B16).
- 참고치는 여러 줄(정상A / 정상B(경계) / 질환의심)이고 성별(M:/F:)에 따라 다르다. 장부에는 참고치를 옮기지 않는다.
- 같은 결과지에 **분변잠혈(Stool occult blood 정량)**이 함께 나온다(B17).
